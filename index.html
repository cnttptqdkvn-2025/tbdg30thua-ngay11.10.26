Đang đồng bộ với kho GitHub… Xem kho lưu trữ trên GitHub

Để xoá ứng dụng trực tiếp từ trang này, cần một Personal Access Token của GitHub (loại fine-grained, chỉ cấp cho riêng kho , quyền Contents: Read and write). Token chỉ được giữ tạm trong trình duyệt này để gọi GitHub API — không được lưu vào file hay gửi đi bất kỳ nơi nào khác. Nên thoát chế độ quản trị sau khi dùng xong, đặc biệt trên máy dùng chung.

Chế độ quản trị đang bật — nút "Xoá" đã xuất hiện trên các thẻ ứng dụng.
